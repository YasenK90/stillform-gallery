# STILL/FORM — Contemporary Art Gallery

A responsive portfolio project for a fictional independent contemporary art gallery in London.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL Vite displays.

## Features

- "Dark museum drama" art direction: near-black walls, film grain, gallery spotlight gradients, cursor-tracked hero light, and an inverted bone "bright room" visit section
- Oversized Playfair Display headlines against DM Mono micro-labels, with a single ember accent
- Scrolling exhibition ticker, animated hero, cinematic scroll reveals, hover light-up on artworks, and full reduced-motion support
- Responsive phone/tablet/desktop layouts
- Exhibition switcher
- Artwork collection filters and artwork detail modal
- Visit request modal with client-side validation and confirmation state
- Newsletter signup interaction
- Keyboard Escape handling, focus-visible styles, alt text, and touch-friendly mobile navigation

## Demo limitations

The visit request and newsletter forms are front-end demonstrations only. They do not send emails, store records on a server, or create real appointments. Artwork and exhibition photography load from Unsplash URLs, so an internet connection is required for those images and external Google Fonts.
